# Memory Match

Welcome to **Memory Match**, a browser-based memory matching game!

## Live Game

🔗 https://sharonbabatundee-cpu.github.io/memory-match/

## About

Memory Match is an interactive web application where players flip cards to find matching pairs. The game challenges players to test their memory, concentration, and ability to recognize matching patterns.

## Technologies Used

* HTML
* CSS
* JavaScript
* GitHub Pages

## Features

* 🃏 Flip cards to reveal hidden symbols
* 🧠 Test memory and concentration
* 🎯 Find matching pairs of cards
* 🔄 Track revealed cards and matching progress
* 🏆 Challenge yourself to complete the game

## Project Structure

* `index.html` - Game structure
* `css/style.css` - Game styling
* `js/script.js` - Game logic and functionality
* `images/` - Game images and assets
